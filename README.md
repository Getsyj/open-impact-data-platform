# open-impact-data-platform
Take messy public indicator data, turn it into a tested and traceable dataset, report on it in Power BI, and build an AI assistant that has to prove its answers.

The problem
Impact and development reporting (SDG-style indicators) pulls from many sources with mismatched country or state names, different units, missing years, and silent revisions. Teams reconcile this by hand, and dashboards end up showing numbers nobody can trace. Putting an AI chat on top can make it worse, because a model can state a wrong number confidently. This project builds a small platform where every number is traceable and every AI answer is checked.
